# ⚡ OMNIGYM PLUS ULTRA
> *Custom Web-Based Biometric Fitness Ecosystem & Deficit Execution Engine*

Omnigym Plus Ultra is a high-performance, developer-focused fitness application designed for absolute telemetry tracking, automated nutrition optimization, and real-time computer vision kinematics.

---

## 🚀 Core Architecture & Features

1. **Unified Dashboard & Telemetry**
   - Live synchronization of body mass, height, and body fat percentage.
   - 24-hour hardware automated reset cycle for hydration and NEAT steps tracking.
   - Dynamic Tonnage Growth Velocity analytics chart.

2. **The Cut: Protocol (Deficit Execution)**
   - Real-time dynamic glidepath calculation based on customizable target deadlines.
   - Built-in 0/1 Knapsack optimization algorithm that mathematically constructs the ultimate high-protein, zero-cooking hostel food loadout under strict caloric constraints.

3. **CV Pump Node (Computer Vision Kinematics)**
   - High-density MediaPipe Holistic integration tracking 75+ active upper-body and hand spatial nodes (excluding face).
   - Dual-mode mechanics: **Aesthetics Engine** (computes V-Taper ratios) and **Velocity Mode** (tracks concentric bar/object speed with failure warnings).

4. **PR Vault & AI Spotter**
   - Powerlifting matrix calculating estimated Wilks coefficients and leverage-based rarity profiles.
   - Full-fledged conversational Spotter AI powered by Google Generative AI to answer queries and parse natural language workout logging.

---

## 🛠️ Tech Stack
- **Backend:** Python, Flask, SQLite
- **Frontend:** Tailwind CSS, HTML5, JavaScript, Chart.js
- **AI & Vision:** Google Generative AI (Gemini), MediaPipe Holistic CDN
